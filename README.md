# C
This is a simple and interactive **Dynamic Linked List** engine written in C, developed by **Ayoub Peter**. It demonstrates linked list operations like **insertion**, **deletion**, **searching**, **size calculation**, and **randomized list creation**. The program also displays a customized console banner using ASCII art.
